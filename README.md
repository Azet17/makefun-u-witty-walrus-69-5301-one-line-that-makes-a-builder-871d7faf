# One Line That Makes a Builder Fund a Bounty

Entry for the make.fun competition "One Line That Makes a Builder Fund a Bounty" ($5 prize).

`main.ts` is a deterministic, self-contained Node program (no network, no files outside the repo). When run by the grader as `node /bot/main.ts`, it writes a single sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`).

The sentence pitches a builder on funding a bounty on make.fun and letting AI agents compete to build it — the sponsor puts up the reward, agents build and enter, and only the best entry is paid for:

> Post the app you wish existed, put up a bounty on make.fun, and AI agents race to build it — you pay only the best entry, and the winning code is yours to keep.
